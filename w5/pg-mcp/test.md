# PostgreSQL MCP 自然语言查询测试用例

本文档包含针对三个测试数据库（small, medium, large）的自然语言查询测试用例，用于测试 pg-mcp 的自然语言转 SQL 功能。

## 数据库说明

- **pg_mcp_small**: 轻量级电商数据库（客户、产品、订单）
- **pg_mcp_medium**: 产品分析数据库（用户、会话、事件）
- **pg_mcp_large**: 供应链和库存数据库（供应商、仓库、采购订单、库存）

## 测试建议

### 测试流程

1. **基础功能测试**: 从简单查询开始（1-10, 51-60, 111-120）
2. **条件查询测试**: 测试 WHERE 子句处理（11-20, 61-70, 121-130）
3. **关联查询测试**: 测试 JOIN 功能（21-30, 71-80, 131-140）
4. **聚合查询测试**: 测试 GROUP BY 和聚合函数（31-40, 81-90, 141-150）
5. **视图查询测试**: 测试视图的使用（41-43, 91-95, 151-155）
6. **复杂查询测试**: 测试多表 JOIN + 聚合（44-50, 96-105, 156-170）
7. **特殊功能测试**: JSONB、时间函数、审计查询等（106-110, 171-190, 191-200）

### 评估标准

- **准确性**: 生成的 SQL 是否正确执行
- **完整性**: 是否包含所有必要的表和字段
- **效率**: SQL 查询是否优化（是否使用了索引）
- **可读性**: 生成的 SQL 是否清晰易懂
- **安全性**: 是否正确处理了 SQL 注入风险

### 注意事项

- 某些查询可能需要特定的数据库（small/medium/large）
- 时间相关的查询结果可能因执行时间而异
- 聚合查询的结果顺序可能不同，需要关注数据而非顺序
- JSONB 查询需要正确的 JSON 路径语法
- 视图查询需要确保视图存在且可访问

## 预期 SQL 示例

### 简单查询示例

**问题**: "显示所有客户的信息"

**预期 SQL**:
```sql
SELECT * FROM customers;
```

### JOIN 查询示例

**问题**: "显示每个订单的客户姓名和订单总金额"

**预期 SQL**:
```sql
SELECT c.name, o.total
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id;
```

### 聚合查询示例

**问题**: "统计每个客户的订单数量"

**预期 SQL**:
```sql
SELECT customer_id, COUNT(*) AS order_count
FROM orders
GROUP BY customer_id;
```

### 复杂查询示例

**问题**: "查询每个供应商的平均订单金额和订单数量"

**预期 SQL**:
```sql
SELECT s.supplier_id, s.name,
       COUNT(po.po_id) AS order_count,
       AVG(po.total_cost) AS avg_order_amount
FROM suppliers s
LEFT JOIN purchase_orders po ON po.supplier_id = s.supplier_id
GROUP BY s.supplier_id, s.name;
```
