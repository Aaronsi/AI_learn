# GenSlides - AI 图片幻灯片生成器

## 产品概述

GenSlides 是一个本地运行的单页应用（SPA），使用火山方舟 Doubao-Seed-1.8 模型根据文字内容生成图片幻灯片，支持全屏走马灯播放。

---

## 目标

1. **流畅的 Slides 生成** - 提供纯视觉方案，用户输入文字即可生成对应图片
2. **并行图片生成** - Slides 之间图片生成互不影响（基准图需要先生成）
3. **成本控制** - 展示当前 Slides 的总体生成成本

## 非目标

1. 导出成 PPTX 格式

---

## 技术方案

### 后端
- **语言**: Python
- **框架**: FastAPI
- **AI 图片生成**: 火山方舟 Doubao-Seed-1.8 模型
  - 模型 ID: `doubao-seed-1-8-251228`
  - API Endpoint: `https://ark.cn-beijing.volces.com/api/v3`
  - API Key: 通过环境变量 `ARK_API_KEY` 配置

### 前端
- **语言**: TypeScript
- **框架**: React
- **样式**: Tailwind CSS
- **状态管理**: Zustand

### 数据存储
- 不使用数据库
- 不需要权限管理
- 整个 App 运行在本地
- 文件存储结构：
  ```
  ./slides/<slug>/
  ├── outline.yml          # 包含所有的文本信息（侧边栏的 slides 源于此）
  ├── style.jpg            # 用户选择的风格参考图片
  └── images/
      └── <sid>/
          └── <blake3_hash>.jpg   # 某个 slide 下面的某张图片
  ```

## 功能需求

### 1. URL 路由

- 访问 `http://localhost:3003/<slug>` 将加载 `./slides/<slug>/` 目录下的 slides
- 示例：`http://localhost:3003/hello-world` → `./slides/hello-world/`

### 2. 页面布局

#### 2.1 顶部导航栏
- **Logo**: "GenSlides" 位于左上角
- **Slides 标题**: 可编辑的标题区域
- **播放按钮**: 位于右上角，点击后全屏从当前选中的 slide 开始播放

#### 2.2 左侧边栏 - Slides 列表
- 显示所有 slides 的列表（Slide 1, Slide 2, ...）
- 每个 slide 有一个唯一的 `sid`，关联若干图片
- **交互方式**：
  - **单击**: 选中 slide，右侧预览区显示对应图片
  - **双击**: 进入编辑模式，修改 slide 的文字内容
  - **拖拽排序**: 选中 slide 后可拖拽改变顺序，松开后自动保存新顺序
  - **点击 slide 下方**: 出现插入线，按回车在该位置创建新 slide

#### 2.3 右侧预览区
- 显示当前选中 slide 对应的图片
- 中央有播放按钮，点击进入全屏播放模式
- **图片选择逻辑**：
  - 如果存在与当前文字 blake3 hash 一致的图片，显示该图片
  - 如果没有匹配的图片，显示最新生成的一张图片
- **生成按钮**: 当文本内容变化后，如果没有对应文本 hash 的图片，在主图片区域下方显示「生成图片」按钮，用户点击后手动触发图片生成
- **底部缩略图**: 展示当前 slide 的所有历史图片，用户可切换预览

### 3. 图片生成

- 图片根据当前 slide 的文字内容生成
- 使用火山方舟 Doubao-Seed-1.8 模型（模型 ID: `doubao-seed-1-8-251228`）生成图片
- 生成的图片保存到磁盘：`./slides/<slug>/images/<sid>/<blake3_hash>.jpg`
- 一个 slide 可以生成多个图片
- **手动触发**: 文本修改后不自动生成，用户点击「生成图片」按钮后才触发生成
- **风格参考**: 生成图片时会参考用户选择的风格图片，保持整个 slides 风格一致
- 支持并行生成多个 slides 的图片

### 4. 全屏播放（走马灯模式）

- 点击"播放"按钮进入全屏模式
- 从当前选中的 slide 开始依次播放
- 支持自动轮播和手动切换

### 5. 成本统计

- 展示当前 slides 的总体 AI 生成成本

### 6. 风格图片选择

- **首次打开流程**: 当用户首次打开一个 slides 项目（或 outline.yml 中没有 `style` 配置时），弹出风格选择 Popup
- **风格选择 Popup**:
  1. 用户输入一段描述风格的文字（如"科技感、蓝色调、扁平风格"）
  2. 系统调用 AI 生成两张风格参考图
  3. 用户从两张图中选择一张作为该 slides 的风格基准
  4. 选中的风格图片保存到 `./slides/<slug>/style.jpg`，`style.prompt` 和 `style.image` 记录在 outline.yml 中
- **风格应用**: 后续生成任何 slide 图片时，都会参考这张风格图片，确保整体视觉风格一致
- **修改风格**: 用户可以在设置中重新选择风格图片

## 数据结构

### outline.yml 示例

```yaml
title: "Hello World Slides"
style:
  prompt: "科技感、蓝色调、扁平风格"    # 生成风格图片时用户输入的描述
  image: "style.jpg"                   # 用户选择的风格参考图片路径
slides:
  - sid: "slide-001"
    content: "第一张幻灯片的文字内容"
    created_at: "2026-01-27T10:00:00Z"
    updated_at: "2026-01-27T10:30:00Z"
  - sid: "slide-002"
    content: "第二张幻灯片的文字内容"
    created_at: "2026-01-27T10:05:00Z"
    updated_at: "2026-01-27T10:35:00Z"
```

### 图片命名规则

- 路径: `./slides/<slug>/images/<sid>/<blake3_hash>.jpg`
- `<slug>`: slides 项目的唯一标识（如 "hello-world"）
- `<sid>`: slide 的唯一 ID
- `<blake3_hash>`: slide 文字内容的 blake3 哈希值

## API 设计

### 后端 API (FastAPI)

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/slides/{slug}` | 获取指定 slug 的 slides 数据 |
| POST | `/api/slides/{slug}` | 创建新的 slides 项目 |
| PUT | `/api/slides/{slug}` | 更新 slides 数据（outline.yml） |
| PUT | `/api/slides/{slug}/reorder` | 更新 slides 顺序 |
| POST | `/api/slides/{slug}/generate/{sid}` | 为指定 slide 生成图片 |
| GET | `/api/slides/{slug}/images/{sid}` | 获取指定 slide 的所有图片列表 |
| GET | `/api/slides/{slug}/images/{sid}/{hash}.jpg` | 获取指定图片 |
| GET | `/api/slides/{slug}/cost` | 获取当前 slides 的总体成本 |
| POST | `/api/slides/{slug}/style/generate` | 根据描述生成两张风格候选图 |
| POST | `/api/slides/{slug}/style/select` | 选择风格图片（保存到 style.jpg） |
| GET | `/api/slides/{slug}/style` | 获取当前风格图片 |

## 用户流程

### 创建新 Slides

1. 用户访问 `http://localhost:3003/<new-slug>`
2. 系统检测到该 slug 不存在，提示创建新项目
3. 用户确认后，系统创建 `./slides/<new-slug>/` 目录和 `outline.yml`
4. **风格选择 Popup 弹出**（因为没有风格图片）
5. 用户输入风格描述文字
6. 系统生成两张风格候选图
7. 用户选择一张作为风格基准
8. 用户开始添加和编辑 slides

### 编辑 Slide

1. 用户双击左侧列表中的 slide
2. 进入编辑模式，修改文字内容
3. 保存后，如果没有对应 hash 的图片，预览区下方显示「生成图片」按钮
4. 用户点击按钮，系统调用 AI 生成新图片（参考风格图片）
5. 新图片以 blake3 hash 命名保存

### 调整 Slide 顺序

1. 用户在左侧列表中选中一个 slide
2. 拖拽 slide 到目标位置
3. 松开后，系统自动保存新顺序到 outline.yml

### 播放 Slides

1. 用户选中起始 slide
2. 点击右上角"播放"按钮
3. 进入全屏走马灯模式
4. 按 ESC 或点击退出按钮返回编辑界面
